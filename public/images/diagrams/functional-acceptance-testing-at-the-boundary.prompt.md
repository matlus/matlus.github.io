## Drawing brief

```text
Create a landscape pastel architectural infographic on cool ivory paper with
subtle watercolor texture. Use dark navy upright sans-serif text, fine blue ink
outlines, soft blue, translucent mint, butter-yellow and salmon-coral accents,
rounded dimensional isometric platforms, layered tinted rims, gentle shadows
and highlights, luminous curved ribbon arrows, and faint peripheral drafting lines.

Main heading, exact: Functional Acceptance Testing
Second heading line, exact: (Black Box Testing at the Boundary)
Keep the heading prominent but balanced with the diagram, with readable spacing.

Place a large Application / Service platform on the left. Place five smaller
owned-dependency platforms in a column in the middle, with these pictograms from
top to bottom: key, table/grid, SQL database cylinder, file/cloud, lightbulb.
Only the database pictogram has a text label: SQL.

One lightly dashed rounded enclosure surrounds the complete application platform
and all five dependency platforms. Its label is Direct / Owned Dependencies.

Outside that enclosure on the right, place three separate service islands from
top to bottom:
Stable Internal Services, with the explanation Owned by other teams.
Downstream Commercial Service.
Stable External Services, with the explanation Payment Gateway, SendGrid,
Spectrum etc.

Draw exactly eight outgoing arrows from the application: one directly to each
of the five owned dependencies, and one directly to each of the three service
islands. No arrow originates at a dependency pictogram. Use mint for the internal
service path and coral for the commercial-service path. Route the separate blue
external-service path below the five owned platforms, with a clear gap around
the lightbulb. Keep each origin and destination unambiguous and all text readable.

Use shallow layered platforms, softly illustrated dimensional icons, rounded
heading capsules, translucent colour washes and generous empty space. No extra
components, arrows, claims, logos, or watermark.
```

## Generation history

The first generation used an illustrated architectural infographic for style
and a testing-strategy slide for content. Subsequent edits corrected the dashed
enclosure and the direct external-service connection. The final subject-heading
edit removed Testing Strategy and introduced the two heading lines above. A later
enlargement was tried; the owner selected the preceding moderate heading version.
