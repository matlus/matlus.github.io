# Two places to verify: authored diagram brief

Article: Verified, Not Trusted: Expense Analysis, Part Four.
Format: authored SVG, 720 x 855, real upright text. Simple boxology in the
approved pastel palette, rounded boxes and dashed groups; no raster generation.

First group: during one workflow run, a bounded model decision enters code
checks for allowed values, source evidence and required finding IDs. Valid
answers can be used; invalid answers enter correction or stop. Do not imply
that syntactic validity proves semantic correctness or that every operation
uses identical retry behavior.

The verified step results contribute to a completed report and structured
ledger. Second group: the independent eval compares that whole outcome with
the reference key, using code for facts and a judge for supported findings.
Repeated runs produce pass rates and a gate. Keep the distinction that an
allowed model answer can still be the wrong answer.
