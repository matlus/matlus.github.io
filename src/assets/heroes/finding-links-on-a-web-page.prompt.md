# Finding links on a Web page

Article idea: Find links to a target domain with HtmlAgilityPack and C#. A LinkFinder downloads HTML, selects anchor elements, and returns their text and attributes.
Subject: A researcher scans a large unfolded web page on a light table. A magnifying lens picks out several link-shaped chain symbols; only those matching a blue domain swatch are clipped into a neat results tray with their surrounding text strips intact. A small desktop download station and a row of structured document nodes support the extraction process. Fine ink and pencil, blue matched links, gray unrelated links, no readable website names.
