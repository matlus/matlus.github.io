# Expanding Code listings

Hand-drawn technical editorial illustration, fine pen-and-ink linework and cross-hatching, warm ivory paper background, mostly monochrome with sparse selective color accents, visible pencil construction marks, slightly retro instructional-manual character, sophisticated conceptual metaphor, clean white space, detailed but not photorealistic.

Article idea: Expand code listings beyond fixed-width page layouts with jQuery. A wrapper supplies titles and icons, while a temporary overlay displays the full listing.
Subject: A programmer reads a narrow code panel inside a fixed-width browser layout. A small expand handle lifts the panel out into a wider floating reading sheet over the desk, revealing previously hidden line lengths without disturbing the underlying page. The mouse, a ruler marking the original narrow width, and a folded side panel give the mechanism physical clarity. Fine ink with blue original frame and amber expansion handle, no legible code or words.
Composition: one wide landscape scene; all important objects and their connection occupy the middle horizontal third so a very wide banner crop retains the relationship. Airy margins above and below. No text, code, labels, logos, or watermark.
